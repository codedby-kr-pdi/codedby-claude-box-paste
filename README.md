# codedby-claude-box-paste

Claude Code 마켓플레이스 — Windows 콘솔 환경에서 붙여넣기 UX를 개선하는 플러그인 모음.

## 수록 플러그인

| 이름 | 설명 |
|---|---|
| [`terminal-paste`](./plugins/terminal-paste) | AutoHotkey 기반 Shift+Insert · Ctrl+V 붙여넣기 활성화 |

## 설치

Claude Code CLI에서:

```
/plugin marketplace add codedby-kr/codedby-claude-box-paste
/plugin install terminal-paste@codedby-claude-box-paste
```

이후 플러그인 초기 설정:

```
/terminal-paste:install
```

## 요구사항

- Windows 10 이상
- PowerShell 5.1 또는 7
- `winget` (Windows App Installer)
